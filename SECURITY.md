# Security policy

AFGC PC Manager handles driver installers, automatic updates, physical-device
hiding, and elevated setup operations. Please do not publicly disclose a
vulnerability that could enable package substitution, privilege escalation,
unsafe device hiding, or release-signing compromise.

Until a dedicated security contact is published, use GitHub's private
vulnerability reporting feature for this repository. Include affected versions,
reproduction steps, impact, and any suggested mitigation. Do not include real
private keys, access tokens, or unredacted device identifiers.

Only the latest published release will receive security fixes once public
releases begin. Development builds are unsupported.
